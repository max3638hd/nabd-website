# موقع "نبض" — مدونة صحة ولياقة جاهزة لـ Google AdSense

## شو موجود بالمشروع
- `index.html` — الصفحة الرئيسية (مقال مميز + شبكة مقالات + نشرة بريدية)
- `article.html` — مقال: ٧ عادات يومية بسيطة لتحسين لياقتك
- `article-2.html` — مقال: ليش النوم أهم عامل بتجاهله بخطتك الرياضية
- `article-3.html` — مقال: البروتين بدون تعقيد
- `article-4.html` — مقال: روتين تمدد ٥ دقائق أول ما تصحى
- `article-5.html` — مقال: كيف تقلل التوتر اليومي بـ ٣ عادات بسيطة
- `article-6.html` — مقال: هل فعلاً تحتاج ٨ أكواب ماء يوميًا؟
- `about.html` — صفحة عن الموقع
- `privacy.html` — سياسة خصوصية (**مطلوبة إلزاميًا** لقبول AdSense)
- `assets/style.css` — كل التنسيقات

**كل المقالات الستة كاملة المحتوى وجاهزة للنشر فعليًا.**

الموقع متجاوب بالكامل (يشتغل تمام على الموبايل)، وفيه أماكن محددة وواضحة
("مساحة إعلانية") جاهزة لوضع إعلانات AdSense فيها.

---

## خطوات النشر والربح الفعلي

### 1. أضف محتوى حقيقي كافي
Google AdSense ما بيوافق على موقع فيه مقال أو مقالين بس. لازم:
- **10-20 مقال حقيقي** ومفيد ع الأقل (انسخ نمط `article.html` لكل مقال جديد)
- محتوى أصلي (مو منسوخ من مواقع ثانية)
- عدّل `privacy.html` وحط بريدك الحقيقي والتاريخ

### 2. انشر الموقع على الإنترنت
أسهل طرق مجانية للمبتدئين:
- **GitHub Pages** (مجاني تمامًا، خطوات بسيطة)
- **Netlify** أو **Vercel** (اسحب وأفلت المجلد، ويصير عندك رابط مباشرة)
- أو استضافة عادية لو عندك دومين خاص

### 3. قدّم طلب على Google AdSense
1. روح لـ [google.com/adsense](https://www.google.com/adsense)
2. سجّل بموقعك
3. Google بتراجع الموقع (ممكن تاخذ من أيام لأسابيع) وبتتأكد إن فيه:
   - محتوى كافي وأصلي
   - سياسة خصوصية واضحة
   - سهولة تنقل وتصميم لائق (الموقع جاهز لهذا الشرط)
4. بعد الموافقة، بيعطوك كود مثل:
   ```html
   <script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-XXXXXXXXXXXXXXXX" crossorigin="anonymous"></script>
   ```

### 4. ضيف كود AdSense للموقع
- حط السكربت اللي فوق داخل `<head>` بكل صفحة (مكانه محدد بتعليق بالكود)
- بدّل كل `<div class="ad-slot">...</div>` بكود وحدة الإعلان (Ad Unit) اللي
  بتاخذه من لوحة تحكم AdSense لكل موقع إعلان

### 5. اجلب زوار حقيقيين
الربح مرتبط مباشرة بعدد الزوار. أفضل طريقة مجانية:
- تحسين محركات البحث (SEO): عناوين واضحة، كلمات مفتاحية طبيعية بالمقال
- مشاركة المقالات بمواقع التواصل الاجتماعي
- الاستمرارية بنشر محتوى جديد بانتظام

## ملاحظات مهمة
- نموذج النشرة البريدية بالصفحة الرئيسية **شكلي فقط** حاليًا، يحتاج ربط
  بخدمة بريد حقيقية (مثل Mailchimp) إذا بدك تفعّله فعلاً
- كل الصور بالموقع حاليًا عبارة عن تدرجات لونية بديلة — استبدلها بصور حقيقية
  (تقدر تستخدم صور مجانية من Unsplash أو Pexels)
- ٦ مقالات كافية كبداية، لكن يفضّل تستمر تضيف مقالات جديدة بانتظام قبل
  وبعد التقديم لـ AdSense لزيادة فرصة القبول والحفاظ على زوار متكررين
